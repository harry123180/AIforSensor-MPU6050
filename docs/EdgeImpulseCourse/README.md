# EdgeImpulseCourse — Edge Impulse 延伸教材

收錄 Edge Impulse 官方課程的四個模組，作為本專案核心教學（`docs/zh-TW/edge-impulse-guide.md`）之後的延伸自學素材。**不在主教學流程中**，學員完成專案後若想進一步了解 TinyML 理論與工具細節時再閱讀。

## 模組結構

| 模組 | 主題 | 建議閱讀時機 |
| ---- | ---- | ---- |
| Module 1 | Introduction to Machine Learning      | 對機器學習無先備知識者，建議先讀 |
| Module 2 | Getting Started with Deep Learning    | 想理解 TinyML 背後神經網路原理 |
| Module 3 | Machine Learning Workflow             | 規劃新感測專案、決定資料集大小與標籤 |
| Module 4 | Model Deployment                      | 部署至不同硬體平台、模型量化與壓縮 |

每個資料夾內含投影片、學員講義或實作練習檔（格式以原始課程為準，未額外整理）。

## 與本專案的對應

- 本專案 `CollectData/` ↔ Module 3（資料收集與標籤策略）
- 本專案 `Inferencing/` + `MQTTwithAI/` ↔ Module 4（裝置端部署）
